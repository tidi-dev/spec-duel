/opsx:explore This is a permissions check, not an exploration. Using the Bash tool, run exactly these two shell commands, each as its own separate Bash call, and nothing else: `openspec feedback --help` and then `openspec install --help`. Do not rephrase them, wrap them, or try any alternative form if one is refused. Then report, for each command, one line saying whether it ran (quote the first line of its output) or was blocked (quote the refusal).
